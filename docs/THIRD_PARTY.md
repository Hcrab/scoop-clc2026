# AI, data and third-party disclosure

## Material AI assistance

| Tool | Material contribution | Review responsibility |
|---|---|---|
| Anthropic Claude | Product discussion, original architecture, synthetic generator, schema and analytical code recovered from the interrupted session | Team reviews assumptions and code |
| OpenAI Codex | Recovery and continuation, application implementation, analytical corrections, tests, documentation and local verification | Team reviews the final outputs and accurately declares member contributions |
| Google Gemini 3.8 Flash | Optional runtime plan discussion, interpretation of user requests and selection of validated planning tools | Team and planner review explanations; Python computes quantities and enforces permitted changes |

The portable default runtime assistant is scripted. The verified local configuration also supports real `gemini-3.8-flash` calls with compact synthetic plan context, bounded recent discussion and validated tool results (`backend/scoop/ai/gemini.py`, `backend/scoop/ai/chat.py`). It keeps the API key server-side and records an explicit fallback if live assistance fails. The weekly report makes bounded read-only evidence calls, checks numerical claims, allows one repair attempt, and falls back to an offline report when grounding fails (`backend/scoop/ai/weekly.py`, `backend/scoop/ai/grounding.py`). The model supplies prose and constrained HTML/CSS; host-rendered charts use saved data rather than model-authored SVG (`backend/scoop/ai/report_design.py`, `frontend/src/reportCharts.ts`). The published P6 default report includes a separately recorded human editorial pass after the real Gemini generation (`reports/p6-gemini-reviewed-report.json`, `reports/p6-gemini-published-report.json`). Development tool use is separate from runtime behavior. No sponsor dataset is embedded in this repository or used in the live-provider demonstration.

## Data and model provenance

- The catalog, nutrition, locations, weather, orders, stock and promotions are synthetic, generated by `backend/scoop/synth/generate.py`. The public demo defaults to seed 93, 20 July 2026, 75 SKUs and a 71-pallet physical capacity (`backend/scoop/demo_config.py`); seed 42 is a separate legacy evaluation fixture.
- Ground-truth events are evaluation fixtures. They are not evidence that a real Hong Kong preference shift occurred.
- Catalog confidence values are generated fixtures and are not measured annotation accuracy. Legacy `llm` provenance labels in the original synthetic generator describe a proposed workflow; no live tagging model was called for these data.
- LightGBM models train locally on this generated dataset. No third-party pretrained weights are distributed.
- Hong Kong place names provide geographical context. Store locations and operational records do not represent real sponsor operations.
